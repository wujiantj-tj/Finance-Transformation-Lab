# AI for Finance

This section explores practical AI applications in Finance and Controlling.

Topics include:
- AI Finance Weekly newsletter: Controller / CFO Edition
- Cost Analysis Agent
- Forecast Review Agent
- Business Case Generator
- Closing Assistant
- Finance Knowledge Agent

The focus is business value creation rather than technology itself.

## Notes

- `Latest/` is used for the newest AI Finance Weekly materials and current working files.
- `Archive/` stores historical editions by date.
- Existing historical PDFs remain in the repository for continuity while the folder structure is being organized.
