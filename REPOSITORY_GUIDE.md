## Filing conventions

- Put domain knowledge in the relevant domain folder.
- Put a reusable, independently documented assistant or software project under the domain's `Projects/` folder.
- Keep recurring briefings and dated deliverables under a dedicated project folder; use `Latest/` for the current edition and `Archive/YYYY/` for history.
- Keep personal data, raw exports, credentials, API keys, tokens and confidential business material out of this public repository.
- Use descriptive file names; avoid creating a new numbered top-level folder for every new idea.
