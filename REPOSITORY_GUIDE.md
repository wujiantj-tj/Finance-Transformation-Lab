# Repository Guide

## Structure
The repository is organized into seven numbered portfolio areas. Use the root README files for English, Chinese and German navigation.

## Conventions
- Keep one canonical copy of each project.
- Keep project README, plugin metadata, skill instructions and implementation together.
- Archive recurring briefings by date in their dedicated folder.
- Use descriptive file names and update section navigation after changes.
- Do not publish confidential employer/customer data, credentials, personal account identifiers, raw private reading exports or copyrighted book text.
- Avoid empty placeholder documents; add meaningful content before publishing.
